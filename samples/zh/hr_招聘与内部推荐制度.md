# 智联科技有限公司 — 招聘与内部推荐制度（2024版）

本制度规范公司招聘流程、录用审批与内部推荐奖励，由人力资源部负责解释。

## 招聘流程

1. 用人部门在 OA 系统提交招聘需求，经部门总监与 HRBP 审批后开放职位。
2. 简历初筛由招聘组完成，技术类岗位增加一轮在线笔试。
3. 面试共三轮：专业面（用人部门）、交叉面（相邻团队经理）、HR 面。
4. 面试官须在面试结束后 2 个工作日内在招聘系统提交评价。
5. 候选人自最后一轮面试起 5 个工作日内收到录用或婉拒通知。

## 录用审批权限

| 职级         | Offer 审批人          |
| ------------ | --------------------- |
| P1 – P3      | 部门总监 + HRBP       |
| P4           | 部门总监 + 人力资源总监 |
| P5 及以上    | 总经理                |

薪酬包超出职级带宽上限的 Offer，一律须人力资源总监与总经理双批。

## 内部推荐奖励

| 被推荐人职级 | 内推奖金（元） |
| ------------ | -------------- |
| P1 – P2      | 3,000          |
| P3 – P4      | 8,000          |
| P5 及以上    | 15,000         |

- 内推奖金在被推荐人试用期转正后的次月随工资发放。
- 被推荐人入职前 6 个月内投递过同一职位的，不计为内推。
- HR 及用人部门面试官推荐本部门候选人的，不享受内推奖金。

## 背景调查

P4 及以上职级、财务岗与法务岗候选人在发放 Offer 前须完成第三方背景调查，
核实学历、工作履历与竞业限制情况。背景调查不通过的，Offer 自动失效。

## 亲属回避

存在配偶、直系血亲关系的员工，不得处于同一汇报线上的直接上下级岗位，
也不得同时任职于财务、审计、采购等相互制约岗位。入职时须主动申报。
