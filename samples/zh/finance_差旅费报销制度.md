# 智联科技有限公司 — 差旅费与日常报销制度（2024版）

本制度适用于全体员工的因公出差与日常费用报销，由财务部负责解释。

## 差旅住宿标准

| 城市类别         | 职级 P1–P3（元/晚） | 职级 P4–P5（元/晚） | 职级 P6 及以上（元/晚） |
| ---------------- | ------------------- | ------------------- | ----------------------- |
| 一线城市         | 450                 | 600                 | 800                     |
| 二线城市         | 350                 | 450                 | 600                     |
| 其他城市         | 280                 | 350                 | 450                     |
| 境外（美元/晚）  | 120                 | 160                 | 220                     |

一线城市指北京、上海、广州、深圳。超标部分由员工自理。

## 餐费补贴

| 出差类型 | 补贴标准             |
| -------- | -------------------- |
| 国内出差 | 150 元/天            |
| 境外出差 | 60 美元/天           |

餐费补贴按出差自然天数计算，无需发票，随差旅报销一并发放。

## 交通标准

- 高铁/动车：P5 及以下乘坐二等座，P6 及以上可乘坐一等座。
- 飞机：4 小时以内航段乘坐经济舱；P6 及以上或连续飞行超过 8 小时可乘坐公务舱。
- 市内交通：凭票实报实销，鼓励使用网约车企业版。

## 报销审批额度

| 单笔报销金额（元） | 审批人             |
| ------------------ | ------------------ |
| 5,000 以下         | 直属经理           |
| 5,000 – 20,000     | 部门总监           |
| 20,000 – 50,000    | 财务总监           |
| 50,000 以上        | 总经理             |

## 报销时限与要求

1. 费用发生后 30 天内提交报销，跨年费用最迟于次年 1 月 15 日前提交。
2. 报销须提供增值税发票，抬头为"智联科技有限公司"，税号 91110000XXXXXXXXXX。
3. 单张发票金额超过 1,000 元的餐饮费须注明事由及陪同人员。
4. 财务部审核通过后，报销款在 7 个工作日内支付至工资卡。
