# IntelliKnow KMS — 中文测试问答手册

本手册配套 `samples/zh/` 目录下的测试文档使用。将全部文档上传至对应的
Intent Space（HR / Legal / Finance / General）并等待状态变为 Processed 后，
即可在 Telegram 或 Teams 中按下表提问，验证意图分类、检索与引用是否正确。

## 使用方法

1. Admin UI → KB Management，按文件名前缀上传到对应空间（hr_ → HR，legal_ → Legal，finance_ → Finance，general_ → General）。
2. 在 Telegram / Teams 向机器人提问下列问题。
3. 对照"预期答案要点"检查回答内容，并确认引用（Sources）指向"来源文档"。

## 进阶测试场景

| 场景 | 测试问题 | 预期行为 |
|------|---------|---------|
| 意图分类边界 | "出差报销的发票抬头写什么？" | 分类到 Finance，答"智联科技有限公司"及税号 |
| 跨空间相近话题 | "离职后多久内的发明算公司的？" | 分类到 Legal（1 年内职务发明），不应命中 HR 文档 |
| 表格检索 | "P5 经理在二线城市住宿标准？" | 从住宿标准表中取 450 元/晚，表格不应被拆散 |
| 知识库无答案 | "公司股票代码是多少？" | 触发无匹配兜底回复，不应编造答案 |
| 低置信度回退 | "今天天气怎么样？" | 回退到 General 空间或返回无匹配提示 |
| 引用校验 | 任意上述问题 | 回答末尾的 Sources 应指向正确的来源文档 |
