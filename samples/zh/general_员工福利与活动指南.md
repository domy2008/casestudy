# 智联科技有限公司 — 员工福利与活动指南（2024版）

本指南介绍公司各项员工福利与文化活动，由行政部与人力资源部共同维护。

## 节日福利

| 节日     | 福利内容               |
| -------- | ---------------------- |
| 春节     | 1,000 元购物卡 + 年货礼盒 |
| 端午节   | 300 元粽子礼券         |
| 中秋节   | 500 元月饼礼盒         |
| 生日     | 200 元生日券 + 生日假半天 |
| 妇女节   | 女员工半天假 + 鲜花    |

## 健康福利

- 每年一次免费全面体检，体检机构可在 3 家合作机构中自选。
- 补充商业医疗保险覆盖员工本人，可自费为配偶和子女加保。
- 公司健身房免费开放，工作日 7:00 – 21:00；每周二、四晚有瑜伽课。
- 每年报销运动费用（健身卡、球类场地）上限 1,200 元。

## 餐饮与下午茶

员工食堂提供午餐和晚餐，公司补贴后午餐 10 元/餐、晚餐免费（加班至 19:30 后）。
每周三下午 15:30 提供免费下午茶。

## 团建与年会

- 每个部门每人每季度 300 元团建经费，跨季度不累计。
- 公司年会于每年 1 月举行，含年度评优颁奖与抽奖，特等奖为 10,000 元旅游基金。

## 学习与发展

1. 每人每年 2,000 元培训经费，可用于外部课程、认证考试与技术大会门票。
2. 通过公司认可的职业认证（如 PMP、CPA、AWS 认证）可额外报销考试费一次。
3. 内部讲师每完成一次 1 小时以上分享，奖励 500 元课酬。

## 其他福利

满 3 年员工可申请一次为期 5 天的带薪"充电假"（每 3 年一次）。
员工子女考入大学的，公司赠送 2,000 元教育贺金。
