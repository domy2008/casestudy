# 智联科技有限公司 — 办公安全与应急指南（2024版）

本指南帮助员工了解办公区安全设施与突发事件处置流程，由行政部安全组维护。

## 应急联系电话

| 事项         | 电话（内线） |
| ------------ | ------------ |
| 行政前台     | 8000         |
| IT 服务台    | 8100         |
| 安保值班室   | 8110（24 小时） |
| 医务室       | 8120         |
| 信息安全部   | 8130         |

火警请直接拨打 119，医疗急救拨打 120，然后通知安保值班室。

## 消防与疏散

- 公司每半年组织一次全员消防疏散演练，具体时间由行政部提前一周通知。
- 火灾发生时请走安全楼梯疏散，禁止使用电梯。
- 疏散集合点为园区南门广场，到达后向本部门安全员报到点名。
- 每层茶水间配有灭火器与急救箱，一楼大堂配有 AED（自动体外除颤器）。

## 医务室

医务室位于 3 楼 301 室，开放时间为工作日 9:00 – 17:30，
提供基础诊疗、常用药品领取与血压测量服务。

## 极端天气办公安排

| 预警级别       | 办公安排                     |
| -------------- | ---------------------------- |
| 台风/暴雨黄色  | 正常办公，可申请弹性到岗     |
| 台风/暴雨橙色  | 建议远程办公，通勤注意安全   |
| 台风/暴雨红色  | 全员居家办公，行政部 OA 通知 |

极端天气居家办公无需另行审批，考勤按正常出勤记录。

## 工位与用电安全

1. 禁止在工位使用大功率电器（电暖器、电磁炉等）。
2. 下班离开前请关闭显示器与工位电源插排。
3. 笔记本电脑过夜充电请放置于阻燃桌面，勿覆盖散热口。

## 失物与可疑情况

拾获失物请交至行政前台登记；发现可疑人员或无人认领的可疑物品，
请勿自行处置，立即联系安保值班室（分机 8110）。
